# Sitemap standard

A [throughline](https://github.com/rhodium-org/throughline) graph that states the
model a website is described in: its pages and the site's tree, the components on
each page and where they are placed, the elements a person reads or acts on, where
each leads, who may reach each page, and the journeys people take. A tool reading a
graph that follows it can draw the sitemap, a wireframe of every page and a
storyboard of every journey, and a checker can test the design against its own
criteria, the same way every time.

The declarations are being proposed; see the open pull request.
